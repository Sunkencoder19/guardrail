Design a premium, developer-first Guardrail Dashboard that feels like a blend of Bloomberg Terminal's information density and operational seriousness, GitHub Security's developer workflow, and Linear's clean spacing and polished interactions, while maintaining the exact dark visual language established by the landing page. The layout should consist of a compact left sidebar containing only Dashboard, Projects, Findings, and Reports (omit Settings for V1 since it has no meaningful functionality yet), with the user profile and logout positioned at the bottom, and a clean top navigation displaying a personalized greeting ("Good Afternoon, Fattesing 👋") on the left and Search, Notifications, and Profile controls on the right. The first and most dominant panel must be a large Security Health card showing the overall system status (e.g., SECURE), a prominent security score (e.g., 92/100), last scan timestamp, repository count, and total open findings, immediately answering whether the platform is secure. Below it, display a compact four-card metrics grid for Critical, High, Medium, and Low vulnerabilities, with each card designed to become clickable in the future. Include a Security Trend section featuring a clean line chart visualizing vulnerability trends over the last 30 days to indicate whether the project's security posture is improving, alongside a Recent Activity timeline that chronologically displays operational events such as repository cloned, Semgrep started, repository scanned, vulnerability detected, and report generated, making the application feel active without unnecessary animations. Add an Active Repositories table listing repository name, programming language, security score, last scan timestamp, and current status, followed by a Critical Findings panel highlighting the five highest-priority vulnerabilities (e.g., SQL Injection, Hardcoded Secret) with severity, affected file, and status, along with a "View All" action. Include a compact Quick Actions panel containing actions such as Scan Repository, Generate Report, and Add Repository for immediate workflows. The dashboard should use the established color palette (#0A0C10 background, #12151C cards, #20242E borders, #4C6FFF primary accent) with status colors reserved for Critical (red), High (orange), Medium (yellow), Low (blue/gray), and Healthy (green). Typography should use Space Grotesk exclusively for the greeting, Geist for all interface text, and JetBrains Mono for technical values, timestamps, and operational data. Motion should remain subtle and purposeful, limited to card hover states, animated counters, smooth chart rendering, and page transitions, avoiding flashy effects. Architect the dashboard as reusable components consisting of Sidebar, Topbar, SecurityHealth, MetricsGrid, TrendChart, RecentActivity, RepositoryTable, CriticalFindings, and QuickActions, while ensuring the entire interface answers three questions within seconds: Is everything okay? If not, where is the problem? What should I fix first? The overall experience should feel like a professional security operations center rather than a generic admin dashboard, prioritizing clarity, operational awareness, and meaningful information over decorative UI.
